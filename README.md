Bienvenue sur le CandyCrush v2 de Gaspard, Marin et Axel.
Ce code a été réalisé en Python dans l'objectif d'un projet de groupe en ISN.
Pour lancer le programme via Tkinter (recommandé) :
• Aller dans le repo "tkinter"

- Lancer le programme main.py accessible dans le même fichier - Ne rien sortir du fichier python car cela risquerait de rendre le code inexecutable
  Pour lancer le programme via Matplotlib:
  • Aller dans le repo Matplotlib
- Lancer le programme main_mat.py
